# Onanefe Addison — Data Analyst Portfolio

A single-page portfolio for **Onanefe Addison** (OnanefeTGA), a data analyst in Nigeria working in SQL, Excel and Power BI.

## What's here

| Path | Contents |
| --- | --- |
| `index.html` | The whole site: layout, styles, charts and case studies in one file |
| `images/` | Power BI dashboard screenshots used in the case studies |
| `Onanefe_Addison_CV.pdf` | The CV behind the **Resume** button |

## Case studies

1. **Subscription revenue decline:** MySQL root-cause analysis and Power BI.
2. **E-commerce customer churn:** MySQL hypothesis testing and Power BI.
3. **Climate shocks & food insecurity:** MySQL exploratory analysis for NGOs and insurers.

All projects use simulated practice datasets.

## Publishing

Settings → Pages → *Deploy from a branch* → `main` / `(root)`.
The site is plain HTML, so there is no build step: edit `index.html`, commit, and it updates.
